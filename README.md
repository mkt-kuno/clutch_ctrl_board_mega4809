# 生研式三軸試験機 コントロールBOX 制御ファームウェア

Microchip **ATmega4809** を用いた、生研式三軸試験機（Seiken-type Triaxial Testing Apparatus）コントロールBOXのリプレイス用制御ファームウェアです。

従来ハードウェア（タイマーリレーや個別ディスクリート回路など）で構成されていた**クラッチディレイOFFタイマー機能をソフトウェアステートマシンとして完全実装**し、回路の大幅なシンプル化・高信頼化・保守性向上を実現しています。

---

## 1. 特徴 & システム概要

- **単一24V電源系統 & MOSFET独立駆動**
  - 単一 24V DC 電源でシステム全体を動作（ロジック系は基板上で 5V に降圧）。
  - 4系統の電磁クラッチ（上昇、下降、保持ブレーキ、高速移動）を N-ch MOSFET により完全独立してON/OFF駆動。
- **ソフトウェアによるクラッチディレイOFFタイマー（DelayedClutch FSM）**
  - クラッチ切替時のショック軽減およびトルク抜け防止のためのクロスオーバー制御をファームウェアで完全実現。
  - **立ち下がりエッジラッチ方式**: 制御入力がOFFへ遷移した瞬間に現在のアナログ設定値を遅延時間として固定ラッチし、タイマーカウント中の誤動作を防止。
- **アナログ遅延時間調整（POT + バックグラウンドADC + IIR-LPF）**
  - ブレーキ・上昇・下降の3軸それぞれに独立した調整ボリューム（POT）を装備（0.1s 〜 1.0s の連続可変）。
  - ADC割り込み駆動による完全バックグラウンドサンプリングと、1/32指数移動平均フィルタ（IIR-LPF）による電気ノイズ除去。
- **独立リミットスイッチ & 多重安全インターロック（SafetyMonitor）**
  - 上限リミット（Max）および下限リミット（Min）の**独立スイッチ入力**（アクティブLOW）。
  - 非常停止（Kill）、フリースイッチ（Free）を含む緊急停止ライン。安全停止要因の発生時は直ちに全クラッチ出力を完全遮断。
  - 要因別の状態表示LEDおよび外部機器向け状態通知信号を装備。
- **高速移動（FAST）モード & 速度ノブ安全連動**
  - FASTモード時のみリレーを励磁して速度調整ノブを開放（有効化）。
  - 通常載荷時はノブ端子をNC接点で短絡（速度0固定）とし、試験中の誤操作による急加速をハードウェア・ソフトウェア双方で防止。
- **デュアル制御モード（MANUAL / COMPUTER）**
  - 操作盤の手動スイッチによる「MANUALモード」と、外部計測・自動載荷制御PCからの接点信号による「COMPUTERモード」のシームレスな切り替え。
- **SerialUPDI 書き込み回路（470Ω仕様）**
  - MCU I/O が 5V 確定仕様のため、一般的な USB-UART 変換器の TX-RX 間に **470Ω 抵抗** を配置した SerialUPDI 回路により、115200 bps での安定した高速書き込みに対応。

## 2. ハードウェア仕様

| 項目 | 仕様 | 備考 |
|---|---|---|
| **マイコン (MCU)** | Microchip ATmega4809 (48ピン) | MegaCoreX プラットフォーム |
| **動作周波数** | 20 MHz (内部高周波オシレータ) | 水晶発振子不要 (Crystal-less) |
| **I/O 電圧** | **5.0 V 固定** | BOD 4.3V 監視による電圧低下暴走防止 |
| **主電源電圧** | **24 V DC (単一電源)** | ロジック回路用 5V は基板内降圧 |
| **クラッチ駆動素子** | N-ch MOSFET (4系統独立) | 24V系電磁クラッチ直接駆動 |
| **リミットスイッチ** | 上限 (Max) / 下限 (Min) 独立配線 | アクティブ LOW (5V: 正常 / 0V: 動作) |
| **書込プロトコル** | SerialUPDI (115200 bps) | TX-RX間: 470Ω 抵抗 |

## 4. 制御ロジック & 動作ステートマシン

### 優先度アーキテクチャ
システムループ（`MachineController::update`）では、厳格な優先度制御を実施しています。

```
[ 入力評価 ]
     │
     ▼
[ 優先度 1: 安全停止 (SafetyStop) ]
     ├─ リミット (Max/Min) 検出、非常停止 (Kill)、フリーSW 検出
     └─ 一致した場合: 全クラッチを即時強制OFF (forceAllOff)、速度ノブ短絡
     │ (安全時のみ次へ)
     ▼
[ 優先度 2: 高速移動 (FAST) ]
     ├─ SW_FAST_ENA == HIGH
     └─ 一致した場合: 移動クラッチ即時ON、ノブ短絡解除、載荷系クラッチ即時OFF
     │ (通常載荷時のみ次へ)
     ▼
[ 優先度 3: 通常載荷 (NORMAL) ]
     ├─ 制御モード判定 (MANUAL / COMPUTER)
     ├─ 目標クラッチ選択 (保持 / 上昇 / 下降)
     └─ 各軸 DelayedClutch FSM により OFF-DELAY クロスオーバー更新
```

### ソフトウェア OFF-DELAY ステートマシン (`DelayedClutch`)
トルク抜けや機構の噛み合い離脱時のショックを防ぐため、各クラッチ出力は3状態のステートマシンで管理されます。

```
     targetOn == true
 [ IDLE ] ────────────► [ ACTIVE ]
 (出力OFF)               (出力ON)
    ▲                        │
    │                        │ targetOn == false
    │                        │ (立ち下がりエッジで現在POT遅延時間をラッチ)
    │                        ▼
    │                [ OFF_DELAYING ]
    │                (出力HIGH保持 / タイマー監視)
    │                        │
    └────────────────────────┘
       経過時間 >= ラッチ遅延時間 (満了)
       (※期間中に再度 targetOn == true になった場合は ACTIVE へ復帰)
```

## 5. 書込回路 (SerialUPDI)

MCU I/O が 5V 固定のため、一般的な USB-UART 変換モジュール（FT232, CH340, CP2102 など）を使用し、**470Ω** の電流制限・波形整形抵抗を介して UPDI 端子（PF6 / Pin 36）に接続します。

```
USB-UART 変換器             ATmega4809
   [ TXD ] ───[ 470Ω ]───┬─── [ UPDI / PF6 ]
                         │
   [ RXD ] ──────────────┘
   [ GND ] ────────────────── [ GND ]
   [ 5V  ] ────────────────── [ VDD ]
```

## 6. ビルド & 書き込み手順

本プロジェクトは **VS Code + PlatformIO** 環境に最適化されています。

### ビルド (コンパイル)
```bash
pio run
```

### マイコンへの書き込み (SerialUPDI)
```bash
pio run -t upload
```

### ヒューズ設定・動作定義 (`platformio.ini`)
- **コア**: MegaCoreX (Arduino framework)
- **クロック**: 20MHz (内部発振)
- **BOD設定**: 4.3V (20MHz安定動作用)
- **リセットピン**: UPDI 専用ピンに固定 (`board_hardware.rstpin = updi`)
- **ブートローダ**: なし (`no_bootloader` / SerialUPDI によるダイレクト書込)
